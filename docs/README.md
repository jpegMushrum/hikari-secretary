## Актуальная граница версии

В `v0.9.0` администраторы управляют ботом в личных сообщениях Telegram, а
участники регистрируются и получают уведомления через тот же бот. Веб-панель и
переход на PostgreSQL относятся к следующему направлению развития и не входят в
текущую реализацию.
