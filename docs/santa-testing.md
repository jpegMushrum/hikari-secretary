# Локальная проверка «Тайного Санты»

Выполняйте команды из корня платформы. В новом checkout создайте
`targets.json` по `targets.example.json`. Для этого сценария достаточно
целей из примера. Остановите другой локальный стенд, если он уже использует
порты 5173 или 55439.

```powershell
docker compose --env-file .env.example -p hikari-santa-test -f docker-compose.bot-local.yml up -d --build backend gateway miniapp
docker compose --env-file .env.example -p hikari-santa-test -f docker-compose.bot-local.yml ps
```

Compose создаёт отдельный проект и отдельный том PostgreSQL. Браузерный
gateway использует вымышленные аккаунты. Контейнер бота и токен Telegram
для проверки не нужны.

Когда `backend` станет `healthy`, подготовьте сезон:

```powershell
docker compose --env-file .env.example -p hikari-santa-test -f docker-compose.bot-local.yml exec -T backend /app/api santa-start
```

Первый вызов создаёт сезон в состоянии подготовки. Повторный вызов до
завершения возвращает тот же сезон с его текущим состоянием и настройками.
Для повторного прогона используйте сброс в панели по шагу 6.

При проверке жеребьёвки учитывайте три правила сезона.

- Запись на обмен подарками и регистрация на встречу оформляются отдельно.
  Изменение даты обмена сдвигает ещё не отправленное напоминание.
- Для первой жеребьёвки нужны минимум три человека. Автоматическое распределение
  образует цикл без взаимных пар. Ручные правки сохраняют уникальность
  получателей. Если состав изменился, администратор готовит новый черновик.
- Подтверждение сохраняет назначения и задания на рассылку одной транзакцией.
  Повторное подтверждение сохраняет те же пары и не создаёт новую рассылку.

1. Откройте [панель администратора](http://localhost:5173/admin/santa).
   В «Настройках сезона» задайте бюджет, будущий срок записи, дату и время
   обмена и интервал напоминания. Конец записи должен быть раньше обмена.
   Форма принимает время по Москве. Miniapp передаёт его API в UTC.
   Нажмите «Открыть участникам».
2. В боковом меню смените «Тестовый профиль» на Аню, Борю и Веру по очереди.
   Каждый профиль открывает [карточку участника](http://localhost:5173/santa).
   Пункт «Тайный Санта» находится внизу списка разделов. Проверьте, что
   до конца записи меню показывает число полных дней, а при сроке меньше
   суток — часы и минуты в формате ЧЧ:ММ. Задайте конец записи и обмен
   через несколько минут и дождитесь каждого срока. Сначала меню должно
   переключиться на отсчёт «До итоговой встречи», а при наступлении
   встречи показать дату обмена. Затем снова задайте будущие сроки.
   Заполните пожелания и
   нажмите «Подтвердить участие» от каждого профиля. Проверьте оба действия
   в окне «Отменить участие?». «Остаться» сохраняет заявку, а «Да, отменить
   участие» удаляет её из таблицы администратора. После перезагрузки формы
   участник видит свои ранее сохранённые пожелания и может записаться снова
   до конца записи. Ответы о присутствии появляются после рассылки назначений.
3. Вернитесь в профиль администратора. Нажмите «Перемешать», проверьте
   три назначения в открывшемся окне. Нажмите на имя, чтобы раскрыть
   пожелания под ним. Попробуйте перетащить подопечного с раскрытыми
   пожеланиями за ручку в правой колонке и убедитесь, что раскрытие следует
   за человеком. Жёлтый цвет и подпись «Раньше» отмечают дарителей, у которых
   изменился подопечный относительно исходного черновика. Проверьте также
   перемещение стрелками ↑ и ↓ на ручке. Попробуйте переместить подопечного
   на строку, где даритель из исходной строки сейчас указан как подопечный.
   Проверьте, что каждый фигурирует как подопечный ровно раз и никто не дарит себе.
   Нажмите «Сохранить черновик». Для повторной проверки используйте «Открыть
   черновик». В режиме участника черновик скрыт. Выберите «Подтвердить и разослать»,
   затем «Разослать назначения», чтобы зафиксировать итоговый вариант.
4. Переключитесь на каждого участника. Проверьте, что меню показывает
   отсчёт «До итоговой встречи», даже если прежний срок записи ещё
   не наступил. В карточке видны
   имя и ссылка на Telegram только назначенного подопечного, а его пожелания
   показаны отдельной цитатой. В разделе «Тестовые уведомления»
   бокового меню видны личные задания из очереди со ссылками. Это локальная
   проверка адресатов и ссылок.
   Можно изменить пожелания одного участника и проверить уведомление
   в профиле его текущего дарителя. Проверьте «Не смогу прийти», затем
   «Всё-таки приду». В обоих новых уведомлениях администратора текст ведёт
   в панель Санты, а отдельная ссылка «Открыть профиль» указывает на
   Telegram-профиль ответившего участника. У вымышленных профилей проверьте
   адрес ссылки в браузере без перехода в Telegram. Для участника с
   Telegram-именем адрес имеет вид `https://t.me/<username>`, для
   участника без него — `tg://user?id=<telegram_id>`. У ранее созданных
   уведомлений поле ссылки на профиль может отсутствовать.
   До первого ответа в форме уже выбрано «Нет», а в карточке администратора
   отображается «Не подготовил».
   Последовательно выберите «Подарок заказан (в пути)», «Нет» и «Подарок готов».
   После каждого выбора проверьте сохранённый ответ. При выборе «Нет»
   проверьте, что у администратора не появилось уведомление о готовности.
   В таблице администратора проверьте зелёную отметку готового подарка
   и её легенду. Откройте карточку дарителя и проверьте ссылку на Telegram,
   имя подопечного и отсутствие блока «Подготовленный подарок», пока
   описание пустое. Сохраните описание объёмом до 2000 символов в профиле
   дарителя. Снова откройте карточку из таблицы администратора. Описание
   сразу видно в блоке «Подготовленный подарок».
5. От получателя подарка из шага 4 отправьте «Запросить выход». Проверьте
   красную отметку и её легенду в таблице администратора. В новом тестовом
   уведомлении проверьте ссылку на профиль участника, который запросил
   выход. Откройте карточку
   этого получателя и нажмите «Исключить участника». В окне «Исключить
   из обмена» проверьте имя и ссылку на Telegram. Предложенные пары видны
   сразу. Найдите жёлтую строку дарителя с новым подопечным и проверьте
   статус «Подарок: Подарок готов». Нажмите на имя дарителя, чтобы увидеть
   сохранённое описание подарка, на имя нового подопечного, чтобы увидеть
   его пожелания, и на «Раньше: …», чтобы увидеть пожелания исключаемого.
   Нажмите «Подтвердить исключение». Оставшиеся двое дарят подарки друг другу.
   Проверьте новые назначения и персональные уведомления об изменении и
   исключении. В уведомлении администратора о подтверждении исключения
   ссылка «Открыть профиль» указывает на исключённого участника.
   У дарителя с новым получателем должно остаться прежнее
   описание. В его форме снова выбрано «Нет», а администратор видит
   «Не подготовил».
6. Нажмите «Сбросить тестовый сезон». Сначала отмените действие и проверьте,
   что сезон остался прежним. Затем повторите и подтвердите сброс. Проверьте
   новый номер сезона, статус «Подготовка», прежние настройки и пустой список
   участников. Участники снова увидят сезон после «Открыть участникам».
   Если срок записи прошёл, обновите даты перед открытием.

Если на стенде есть ранее приостановленный сезон (`paused`),
убедитесь, что карточка участника недоступна даже по прямой ссылке.
В панели администратора нажмите «Возобновить доступ» и проверьте,
что карточка снова открывается, а прежние заявки и назначения сохранены.

Для отдельной проверки напоминания оставьте сезон открытым после
утверждения пар и задайте интервал так, чтобы текущее время попало в окно
напоминания до обмена. Backend проверяет сроки примерно раз в минуту.
Уведомление появится у тестового профиля после очередной проверки.
В production напоминание доставляет Telegram-бот.

Остановить стенд с сохранением PostgreSQL можно командой:

```powershell
docker compose --env-file .env.example -p hikari-santa-test -f docker-compose.bot-local.yml down
```
